# FlowScape Scene Content

Public scene discovery and desktop media, independent of application installers.

- [Scene index](scene-index.json)
- [Scene media releases](https://github.com/gillianli/flowscape-content/releases)
- [Desktop installers](https://github.com/gillianli/flowscape-releases/releases)

Use FlowScape Desktop 1.0.13 or later. Choose a scene in Home or Explore, unlock invitation editions before downloading, then choose Enter when verification finishes. Closing Scene Setup does not interrupt a desktop download; playback never starts automatically after download.

Invitation codes are promotional entry gates, not DRM. These media files are public. Private invitation files and GitHub credentials are never published here.

Android media remain Google Play Asset Delivery on-demand packs. This repository provides discovery metadata, not the mobile media backend. New Android packs require a matching application version in Google Play. iOS native store delivery integration is not yet available.

Media revisions are immutable. Publishers upload and verify all files before updating the index. Do not add media releases to the installer repository, because they would interfere with the program update channel.
